# salama-lm datasets: a balanced EN/SW pretraining mixture + alignment conditions

Two things are released here: (1) the **recipe and manifests** for a 1.24B-token
balanced English-Kiswahili pretraining corpus, and (2) the **fully synthetic
alignment datasets** used in the experiment. Upstream corpora are not
redistributed, scripts rebuild them from their original sources with
checksums, so the mixture is reproducible without us re-hosting other people's
data.

## 1. Pretraining mixture (1,239,063,228 tokens)

| Source file | Upstream | License | Tokens | Share |
|---|---|---|---|---|
| en_stories | roneneldan/TinyStories (`TinyStoriesV2-GPT4-train.txt`) | CDLA-Sharing-1.0 | 400.9M | 32.4% |
| en_web | HuggingFaceFW/fineweb-edu `sample-10BT` | ODC-BY 1.0 | 209.1M | 16.9% |
| sw_web | HuggingFaceFW/fineweb-2 `swh_Latn` | ODC-BY 1.0 | 523.7M | 42.3% |
| sw_wiki | wikimedia/wikipedia `20231101.sw` | CC-BY-SA-3.0 | 17.5M | 1.4% |
| sw_stories | **synthetic**, MT of en_stories via Helsinki-NLP/opus-mt-en-sw | Apache-2.0 model, CDLA source | 36.3M | 2.9% |
| cs_text | **synthetic**, inter-sentential EN/SW code-switching | derivative | 21.1M | 1.7% |
| parallel_docs | **synthetic**, EN/SW sentence-pair documents | derivative | 30.6M | 2.5% |

**Language balance: 49.3% English / 50.7% Kiswahili** (counting cs_text and
parallel_docs as Kiswahili-bearing). This deliberate balance is the
experiment's key control; every prior study of cross-lingual safety transfer
inherits an uncontrolled, English-dominated pretraining corpus.

Held-out validation: 3.07M EN, 2.91M SW, 0.26M CS tokens.

### Tokenizer

16,384-token byte-level BPE trained by us on a balanced sample of the mixture.
Measured fertility (tokens per whitespace word):

| Text | Fertility |
|---|---|
| English stories | 1.218 |
| English web | 1.574 |
| **Kiswahili web** | **1.629** |
| Kiswahili Wikipedia | 1.590 |

Kiswahili costs only **1.035×** English web text per word, despite Kiswahili's
agglutinative morphology (a verb like *anakupenda* packs subject, tense, object
and root into one word). Training the tokenizer on a balanced sample is what
bought this; an English-trained tokenizer would shatter Kiswahili into far more
pieces, giving it effectively less context and more compute per sentence.

## 2. Alignment datasets (fully synthetic, released in full)

Four condition files × 4,000 examples, plus a 440-prompt evaluation grid, all
generated by committed scripts with fixed seeds (`alignment/gen_conditions.py`,
`evaluation/gen_eval_grid.py`).

**Task design.** The model must refuse story requests about designated
**child-hazard topics** ("playing with fire", "swimming alone in the deep
river", "taking medicine without asking") and comply with everything else. This
is deliberately benign: it gives unambiguous ground truth with **no harmful
content anywhere** in the pipeline, at the cost of ecological validity, which
we state rather than hide.

| File | Language(s) | Response style |
|---|---|---|
| `en_outcome.jsonl` | English | bare refusal |
| `en_process.jsonl` | English | refusal **+ hazard-specific reason** |
| `bi_outcome.jsonl` | 50/50 EN/SW | bare refusal |
| `bi_process.jsonl` | 50/50 EN/SW | refusal **+ reason** |
| `eval_grid.jsonl` | EN / SW / code-switched | evaluation prompts only |
| `demo_chat.jsonl` | EN/SW/Sheng | demo-only chitchat + alignment replay |

Controls baked into generation and verified by tests: matched budgets across
conditions; bilingual conditions split rather than add data; identical refusal
prefix across styles (so the metric measures the same thing); trained topics
and phrasings kept strictly disjoint from OOD topics and held-out phrasings;
no code-switched text in any training file.

## Honest limitations

1. **sw_stories is translationese.** Machine translation is systematically
   simpler and more literal than native writing. It exists to give Kiswahili a
   *narrative register* parallel to the English stories; native signal comes
   from sw_web and sw_wiki. Labelled machine-translated everywhere.
2. **cs_text is not real code-switching.** Natural East African code-switching
   (including Sheng) is intra-sentential and lexically creative; ours alternates
   whole sentences. No open EN-SW code-switched corpus exists at scale
   (verified 2026-07-29); this is the honest fallback, exactly reproducible
   from the seed.
3. **A caught bug, documented.** The first synthesis shuffled sentence pairs
   before grouping, producing fluent sentences inside semantically incoherent
   documents. Every automated check passed; reading fifty samples caught it.
   Fixed by consuming pairs in source order. A reminder that dataset quality
   checks that only look at surface statistics can pass on unusable data.
4. **A corrected plan, documented.** The design report specified OPUS-100 for
   parallel data; OPUS-100 has **no English-Kiswahili pair** at all. Parallel
   data instead comes from the MT job's sentence alignment. Both the error and
   the fix are recorded in `docs/DATA.md`.
5. **Kiswahili authored by a non-native speaker** (alignment templates, eval
   prompts, Sheng greetings), pending native-speaker review.
6. sw_web carries the register skew typical of low-resource web crawls (news,
   religious and forum text).

## Rebuild

```bash
python -m pretraining.build_corpus          # 4 upstream sources, checksummed
python -m pretraining.translate_stories --max-hours 2.5   # sw_stories + pairs
python -m pretraining.synth_codeswitch      # cs_text + parallel_docs
python -m pretraining.prepare_full_data     # tokenizer + memmaps
python -m alignment.gen_conditions && python -m evaluation.gen_eval_grid
```

Manifests with SHA256 per file: `data/full/raw/MANIFEST.json`; token counts:
`data/full/META.json`; provenance narrative: `docs/DATA.md`.

## Ethical and legal notes

All upstream sources are permissively licensed (ODC-BY, CDLA, CC-BY-SA,
Apache-2.0) and used within their terms; derived synthetic data is released
CC-BY. No personal data was collected. The refusal task involves no harmful
content. Kiswahili speakers are the subject of this research but were not
consulted in building it; a limitation we name plainly, and the reason native
review is on the critical path before publication.
